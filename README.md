## dots (wayland)

> [!NOTE]
> Clone or place this repository in `$HOME/dotfiles` before running the setup scripts.

### Installation

```console
$ ./scripts/iFonts.sh  # Install required fonts
$ ./scripts/setup.sh   # Symlink dotfiles (requires GNU Stow)
```
